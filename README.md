# cuiqingcai-spiders

这是一个爬虫集合仓库，主要案例来自 《python3 网络爬虫开发实战》(作者是崔庆才)。

## Scrapy 框架的使用

[Scrapy官方网站](https://www.scrapy.org/)

- 入门案例：[quotes](https://docs.scrapy.org/en/latest/)

**一些基本的概念**：
1. Engine 引擎
2. Item 数据结构
3. Scheduler 调度器
4. Spiders 爬虫
5. Downloader 下载器
6. Item Pipelines 项目管道
7. Downloader Middlewares 下载中间件
8. Spider Middlewares 爬虫中间件
